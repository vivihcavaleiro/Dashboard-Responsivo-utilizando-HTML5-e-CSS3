# 🏫 Dashboard Escolar - Colégio Futuro

Este projeto consiste na interface visual de um **Dashboard Escolar** moderno e responsivo, desenvolvido com **HTML5** e **CSS3** puros.

## 🚀 Funcionalidades
- **Cabeçalho informativo**: Nome da instituição, logo e data.
- **Menu Lateral**: Navegação por categorias.
- **Cards de Métricas**: Indicadores de alunos, professores, turmas, etc.
- **Tabela de Alunos**: Exibição dos alunos matriculados e seus respectivos status.
- **Seção de Avisos e Eventos**: Calendário e avisos institucionais.
- **Layout Responsivo**: Adaptável para dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox, CSS Grid)
